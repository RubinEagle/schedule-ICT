# schedule-ICT

Расписание ИВТ-14МО и ПИЭ-13МО: статичный сайт (React + Vite) с подпиской на календарь.

## Две вкладки

Переключатель внизу экрана:

- **`/` — «Локально».** Личное расписание из `data/local-schedule.json`. Это основной источник: его правят вручную, CI его не трогает.
- **`/table/` — «Из таблицы».** Расписание обеих групп, которое разобрано из общей xlsx. Здесь же выбираются курсы по выбору и видны
  **отличия от локального расписания**. Счётчик отличий показывается на вкладке в таб-баре и в подвале главной.

В конце каждой страницы есть кнопка «Синхронизировать календарь». У каждой вкладки своя подписка:
`/local/ics/<вариант>.ics` и `/ics/<группа>/<вариант>.ics`.

## Как это работает

- **Локально.** `npm run local` (`scripts/build-local.ts`) читает `data/local-schedule.json` и пишет `public/local/schedule.json`
  и `public/local/ics/*.ics`. Скрипт запускается сам перед `dev` и `build`, результат в git не хранится (`.gitignore`).
  Timeweb пересобирает календарь при каждом пуше.
- **Таблица.** Источник — xlsx «Осень 2026 (26-27 уч.г)» на публичном Яндекс Диске. `npm run data` скачивает файл, разбирает лист
  «Бакалавры и магистры» (`shared/parse-xlsx.ts`) и пишет `public/data/schedule.json` и `public/ics/<группа>/<вариант>.ics`:
  по одному файлу на каждую комбинацию настроек (выбор к.в., показ факультативов).
- GitHub Actions (`.github/workflows/update-schedule.yml`) делает это **раз в неделю, в воскресенье в 18:00 МСК**, и коммитит изменения.
  Запустить вручную можно через *Run workflow*. Пуш в `main` запускает пересборку на Timeweb Apps.
- Отличия считает `shared/diff.ts`: сравнивает сетку «день × пара × числитель/знаменатель» у локального расписания и группы таблицы
  с тем же названием. Даты-исключения и примечания не сравниваются.

## `data/local-schedule.json`

```json
{
  "metadata": {
    "group": "ИВТ-14МО",
    "semester_start": "2026-08-31",
    "semester_end": "2027-01-08",
    "updated_at": "2026-10-01",
    "days_off": ["Среда", "Суббота"]
  },
  "schedule": [
    {
      "day": "Понедельник",
      "pair": 1,
      "start_time": "09:00",
      "end_time": "10:35",
      "subject": "Машинное обучение",
      "teacher": "Быстров Л.Ю.",
      "room": "309",
      "week_type": ["numerator"],
      "optional": false,
      "facultative": false,
      "online": false
    }
  ]
}
```

- `semester_start` — понедельник первой недели. Она считается числителем, если не указано `"first_week": "denominator"`.
  `semester_end` — последний учебный день. `updated_at` — дата правки: показывается на сайте и идёт в календарь.
- `day` — полное название дня («Понедельник») или сокращение («пн»). `week_type` — `["numerator"]` (числитель),
  `["denominator"]` (знаменатель) или оба.
- `optional: true` — курс по выбору (метка «к.в.»), `facultative: true` — факультатив (ФТД, его можно скрыть в настройках).
- `start_time` / `end_time` можно не указывать, тогда подставится стандартное время пары.
- Необязательные поля: `online`, `lecture`, `note`, `start_date` (с какой даты идёт пара), `exclude_dates` (даты, когда её нет).

Если в файле ошибка, `npm run local` (а значит, и сборка) остановится с понятным сообщением вида «Занятие №3: неизвестный день „Пнд“».

## Команды

```
npm install
npm run local         # собрать личное расписание и его календарь
npm run data          # скачать таблицу и сгенерировать данные
npm run data:local    # то же из tests/fixtures/schedule.xlsx
npm run dev           # локальный сервер (сначала npm run local)
npm run build         # сборка в dist/: index.html и table/index.html
npm test              # vitest
```

## Ручные правки парсинга

`data/overrides.json` — объект с ключами `"<группа>/<день 0-5>/<пара>"` (или с суффиксом `/odd`, `/even`), значения:

```json
{
  "pie-13mo/0/5": {
    "options": [{ "title": "Управление ИТ-проектами", "teacher": "Ерофеев А.А.", "online": true }],
    "excludeDates": ["2026-09-14"],
    "note": "14.09 пары не будет"
  },
  "ivt-11mo/0/5": { "remove": true }
}
```

## Timeweb Apps

Тип приложения — Frontend (React / Vite), Node 22, команда сборки `npm run build`, директория `dist`, автодеплой из ветки `main`.
Для сборки нужны devDependencies (`tsx`, `vite`). Страница `/table/` — отдельный `table/index.html`, поэтому SPA-fallback не нужен.
